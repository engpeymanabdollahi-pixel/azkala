**ازکالا** یک پلتفرم فروشگاهی مدرن، مقیاس‌پذیر و چندفروشندگی (Multi-Vendor) است که با تمرکز بر فروش لوازم جانبی دستگاه‌های هوشمند (Device-First) طراحی شده است. این پروژه با رعایت اصول مهندسی نرم‌افزار، الگوی Service/Repository در بک‌اند و معماری ماژولار در فرانت‌اند توسعه یافته است.

---

## 🚀 پشته فناوری (Tech Stack)

### Backend
- **Framework:** Laravel 13.x
- **Language:** PHP 8.3+
- **Database:** MySQL / SQLite
- **Authentication:** Laravel Sanctum
- **Real-time:** Laravel Reverb (WebSockets)
- **Testing:** PHPUnit (338+ Passing Tests)

### Frontend
- **Framework:** React 19.x + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand (Client) + TanStack React Query (Server)
- **Performance:** Lazy Loading, Error Boundaries, Code Splitting

---

## ⚙️ پیش‌نیازها (Prerequisites)

قبل از شروع، مطمئن شوید ابزارهای زیر روی سیستم شما نصب هستند:
- PHP >= 8.3
- Composer
- Node.js >= 20.x (ترجیحاً 22.x)
- MySQL یا SQLite
- Git
